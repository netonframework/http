# http

HTTP for Kotlin/Native on top of `com.netonstream:io`: common types, HTTP/1.1, HTTP/2 (`com.netonstream:http`),
and HTTP/3 over `com.netonstream:quic` (`com.netonstream:http3`). Packages `neton.http`, `neton.http.h1`,
`neton.http.h2`, `neton.http.h3`.

Status: specification draft, see [SPEC.md](SPEC.md). No code yet.
